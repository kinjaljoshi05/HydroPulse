# 📌 Project Overview

HydroIntel AI is an intelligent hydropower analytics platform that combines rainfall and reservoir datasets to generate meaningful insights for decision-makers.

The application performs:

- 📊 Rainfall Data Analysis
- 🌊 Reservoir Level Analysis
- ⚡ Hydropower Generation Forecasting
- ⚠️ Operational Risk Assessment
- 🤖 AI-Based Insights
- 📈 Interactive Executive Dashboard

This project was developed during my **Summer Internship at THDC India Limited (IT Department)**.

# ⚙ Installation

Clone the repository

```bash
git clone https://github.com/Vinayak-123-jpj/HydroIntel-AI.git
```

Go to project folder

```bash
cd HydroIntel-AI
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
streamlit run app.py
```
